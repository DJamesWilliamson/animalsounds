# Make an excited animal sound

Repeat an animal sound in uppercase.

## Usage

``` r
excited_sound(animal, sound, times = 3)
```

## Arguments

- animal:

  A character string containing an animal.

- sound:

  A character string containing an animal sound.

- times:

  Number of times to repeat the sound.

## Value

A character vector.

## Examples

``` r
excited_sound("cow","moo", 3)
#> [1] "The cow says MOO MOO MOO"
```
